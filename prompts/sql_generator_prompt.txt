              is_guard, is_forward, is_center (BOOLEAN)

TEAM LOOKUP:
  dim_team: team_id, team_city, team_name, team_abbrev
  → team_name = 'Warriors' (NOT 'Golden State Warriors')
  → team_abbrev = 'GSW', 'LAL', 'BOS', 'MIA', 'CHI', etc.

SEASON FILTERING:
  season_year column uses format '2023-24' (NOT 2023, NOT '2023')
  → Available on: fact_game, fact_player_game_stats, fact_team_game_stats
  → "last season" = '2023-24' | "this season" = '2024-25'
  → Always filter by season_year unless explicitly spanning multiple seasons

COMMON PATTERNS (copy these patterns exactly)

PPG leader this season:
  SELECT p.first_name || ' ' || p.last_name AS player_name,
         AVG(s.points) AS ppg,
         COUNT(s.game_id) AS games
  FROM fact_player_game_stats s
  JOIN dim_player p ON s.person_id = p.person_id
  WHERE s.season_year = '2023-24'
  GROUP BY p.person_id, p.first_name, p.last_name
  HAVING COUNT(s.game_id) >= 10
  ORDER BY ppg DESC
  LIMIT 10

Team season record:
  SELECT t.team_name,
         COUNT(*) AS games,
         SUM(CASE WHEN s.is_win THEN 1 ELSE 0 END) AS wins,
         SUM(CASE WHEN NOT s.is_win THEN 1 ELSE 0 END) AS losses
  FROM fact_team_game_stats s
  JOIN dim_team t ON s.team_id = t.team_id
  WHERE s.season_year = '2023-24'
  GROUP BY t.team_id, t.team_name
  ORDER BY wins DESC
  LIMIT 30

Head-to-head comparison:
  SELECT p.first_name || ' ' || p.last_name AS player,
         AVG(s.points) AS ppg,
         AVG(s.assists) AS apg,
         AVG(s.rebounds) AS rpg
  FROM fact_player_game_stats s
  JOIN dim_player p ON s.person_id = p.person_id
  WHERE s.season_year = '2023-24'
    AND (p.last_name = 'James' OR p.last_name = 'Durant')
  GROUP BY p.person_id, p.first_name, p.last_name

Clutch plays:
  SELECT player_name, action_type, COUNT(*) AS count
  FROM fact_play_by_play
  WHERE period >= 4 AND clock <= '02:00'
    AND shot_value = 3
  GROUP BY player_name, action_type
  ORDER BY count DESC
  LIMIT 20

═══════════════════════════════════════════════════════
DUCKDB-SPECIFIC SYNTAX
═══════════════════════════════════════════════════════
- String concat: || operator (NOT CONCAT())
- Boolean: TRUE/FALSE (not 1/0 in WHERE)
- Integer division: use CAST(x AS DOUBLE) / y for decimals
- ILIKE for case-insensitive LIKE
- Date math: DATE_DIFF('day', start_date, end_date)
- ROW_NUMBER() OVER (PARTITION BY ... ORDER BY ...)
- No PIVOT syntax — use conditional aggregation instead
